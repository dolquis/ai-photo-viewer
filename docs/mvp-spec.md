# MVP 仕様書

本書は最初のリリース（MVP）で実装する範囲を定義する。原則として
引継ぎ文書 4章を中核機能、5章以降を MVP 後フェーズとする。

## 1. MVP で実装する機能

| ID | 機能 | 概要 |
|---|---|---|
| F-01 | 高速画像ビューワー | フォルダを開いて一覧/サムネイル表示、拡大縮小回転、前後移動、EXIF 表示 |
| F-02 | ローカル DB 管理 | パス・サイズ・更新日時・ハッシュ・EXIF・サムネイル参照を SQLite に保存。フォルダ単位インデックス、変更検知による再解析 |
| F-03 | 重複画像検知 | 完全一致ハッシュ + pHash/dHash による近似重複検出。スコア付き候補表示、削除前に確認必須 |
| F-04 | 類似画像検索 | 画像埋め込みによる類似画像検索 |
| F-05 | 自然言語検索 | 画像埋め込み + テキスト埋め込みで文章検索（類似度スコア付き） |
| F-06 | 自動タグ付け | AI による内容推定タグ。AI/ユーザー確定/ユーザー除外を区別。修正 UI |
| F-07 | 顔検出・人物グループ化 | 顔検出 → 顔特徴量 → 同一人物クラスタリング。人物名付与、統合/分割/削除 |
| F-08 | バックグラウンド AI 解析 | 非同期ジョブキュー、進捗表示、一時停止/再開、解析済みスキップ |
| F-09 | 解析データ削除 | 画像/フォルダ単位の AI 解析結果削除・再生成 |

対応画像形式: JPEG, PNG, WebP, BMP, GIF, TIFF。HEIF/AVIF/RAW は対象外（後続検討）。

## 2. MVP で実装しない機能

OCR 検索、ベストショット選定、画質診断、派生画像ツリー、プライバシー共有前チェック、
AI 補正（アップスケール/ノイズ除去）、クラウド同期、モバイル版、RAW 現像、
高度な画像編集、生成 AI 編集、自動人物名推定。

これらは `docs/roadmap.md` の Phase 5 以降で扱う。

## 4. ユースケース

- UC-1: ユーザーがフォルダを登録 → アプリが画像をインデックスし、背景で AI 解析を開始する。
- UC-2: ユーザーがサムネイルグリッドを高速スクロールして目的の画像を探す。
- UC-3: ユーザーが「夜の神社」と検索 → 類似度順に画像が表示される。
- UC-4: ユーザーが 1 枚を選び「類似画像」から加工違い・連写を見つける。
- UC-5: アプリが重複候補を提示 → ユーザーが保持画像を選び、残りを隔離/削除する。
- UC-6: アプリが顔クラスタを提示 → ユーザーが人物名を付け、誤クラスタを統合/分割する。
- UC-7: ユーザーが特定フォルダの AI 解析結果を削除し、再解析させる。

## 5. 主要ユーザーフロー

### フロー A: 初回セットアップ〜解析

1. 設定画面で監視フォルダを追加。
2. アプリがファイルを走査し、メタデータ/サムネイル/ハッシュを DB 登録。
3. ジョブキューに埋め込み・タグ・顔検出ジョブを投入し、背景で実行。
4. メイン画面下部に進捗を表示。ユーザーは解析中も閲覧可能。

### フロー B: 自然言語検索

1. 検索バーに文章を入力。
2. テキスト埋め込みを生成し、ベクトル索引で近傍画像を取得。
3. 類似度順にサムネイルグリッドへ表示。

### フロー C: 重複整理

1. 重複管理画面で重複グループを開く。
2. 解像度/サイズ/形式/更新日時を比較、推奨保持画像を確認。
3. 確認ダイアログを経て、非保持画像を隔離フォルダへ移動（既定）または削除。

## 6. 受け入れ条件

- AC-1: 数万枚のフォルダでサムネイルグリッドが体感ひっかかりなくスクロールできる。
- AC-2: ネットワークを切断しても F-01〜F-09 が動作する。
- AC-3: 画像ファイル本体・EXIF が解析・閲覧操作で改変されない。
- AC-4: AI 解析中も UI 操作（閲覧・スクロール）がブロックされない。
- AC-5: 解析結果にモデル名・バージョンが記録され、削除・再生成できる。
- AC-6: 重複/類似/顔の削除・統合操作の前に必ずユーザー確認がある。
- AC-7: 顔特徴量・埋め込みなどの解析データが外部送信されない。
- AC-8: GPU/NPU の無い環境でも CPU で全機能が動作する。

## 7. テスト観点

- 機能テスト: 各 F-xx の正常系・異常系（破損画像、巨大画像、ゼロバイト、権限なし）。
- 性能テスト: 1 万/5 万/10 万枚でのインデックス時間・スクロール FPS・検索レスポンス。
- 堅牢性: 解析中のアプリ終了→再起動で解析状態が一貫していること。
- 非破壊性: 解析前後でファイルのバイト列・更新日時が不変であること。
- プライバシー: 解析・検索フロー全体でネットワーク送信が発生しないこと（ネットワーク監視）。
- 回帰: モデル差し替え後の再解析で結果が更新されること。
