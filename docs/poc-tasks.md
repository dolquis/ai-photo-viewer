# 技術検証タスク一覧（Phase 0）

引継ぎ文書 14.6 に対応。実装着手前に作るべき PoC を列挙する。各 PoC は
使い捨て前提で、本実装のコードベースとは分離して計測する。

PoC を Linear Issue 単位へ分割し、実施順・依存・受け入れチェックを一枚にまとめた
**P0 分割計画は [`docs/p0-split-plan.md`](p0-split-plan.md)**（DEV-41 成果物）を参照。

| ID | 検証対象 | 目的・計測項目 | 合格目安 |
|---|---|---|---|
| PoC-1 | 画像表示性能 | Avalonia での大画像表示・拡大縮小・回転の応答性、メモリ使用量 | 数十 MP 画像の表示・操作が体感遅延なし |
| PoC-2 | サムネイル生成 | サムネイル生成速度、キャッシュ I/O、グリッド仮想化スクロール FPS | 5 万枚グリッドが滑らかにスクロール |
| PoC-3 | SQLite 管理 | 10 万行規模での登録・更新・一覧取得・インデックス効果、WAL での並行性 | 一覧ページング取得が 100ms 未満 |
| PoC-4 | pHash 重複検知 | pHash/dHash/aHash の計算速度と、拡張子/解像度/圧縮違いの検出精度 | 加工違いペアをハミング距離で安定検出 |
| PoC-5 | ONNX 画像埋め込み | ONNX Runtime で埋め込み生成、CPU/DirectML EP の速度比較、前処理コスト | CPU のみでも実用的なスループット |
| PoC-6 | ベクトル検索 | 線形探索 / HNSW / `sqlite-vec` の検索速度・精度・メモリを比較 | 10 万件で近傍検索 1 秒以内 |
| PoC-7 | 顔検出 | 顔検出モデルの検出精度・速度、顔特徴量によるクラスタリング品質 | 同一人物が安定して同一クラスタ |
| PoC-8 | 自然言語検索 | テキスト埋め込みと画像埋め込みの整合、日本語クエリでの検索妥当性 | 「夜の神社」等で妥当な上位結果 |

## 実施順と依存関係

1. PoC-1 / PoC-2 / PoC-3 を先行（閲覧基盤の前提検証。Phase 1 に直結）。
2. PoC-4 / PoC-5 を実施（Phase 2 の前提）。
3. PoC-5 の埋め込み結果を用いて PoC-6 / PoC-8 を実施。
4. PoC-7 を実施（Phase 4 の前提）。

## 検証で確定させる設計判断

- UI フレームワーク最終確定（Avalonia の仮想化性能が要件を満たすか）。
- ベクトル検索方式の確定（HNSW か `sqlite-vec` か）。
- 既定の実行プロバイダ（CPU フォールバックの実用性、DirectML の互換性範囲）。
- MVP で採用する具体的なモデル（埋め込み・タグ・顔検出・顔特徴量）。

各 PoC の計測結果は `docs/tech-selection.md` および `docs/roadmap.md` Phase 0 の
完了条件に反映する。
