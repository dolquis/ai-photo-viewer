# プライバシー・安全設計

引継ぎ文書 12章に対応する。本アプリの最重要価値の一つはプライバシー保護である。

## 1. 原則

- 画像を外部送信しない。
- AI 解析結果（タグ・埋め込み等）を外部送信しない。
- 顔特徴量を外部送信しない。
- OCR 結果を外部送信しない。
- すべての解析はローカルで完結する。
- ユーザーは解析データを削除できる。

実装上の担保:

- アプリは AI 解析・検索・閲覧のいずれの経路でもネットワーク通信を行わない。
- 通信が発生し得るのはモデル取得など明示的な操作のみとし、それも任意とする。
- リリーステストでネットワーク監視を行い、解析フロー中の送信ゼロを検証する
  （`docs/mvp-spec.md` テスト観点）。

## 2. プライバシー区分

以下はプライバシーリスクの高い情報として、ローカル保存に限定し慎重に扱う。

- 顔特徴量（`Faces.Embedding`）
- OCR テキスト（`OcrResults.Text`）
- EXIF の GPS 位置情報
- 人物名（`Persons.DisplayName`）

ログにこれらの生データを記録しない（`docs/architecture.md` ログ設計）。

## 3. 削除・リセット機能

引継ぎ文書 12.2 に従い、以下を提供する。

- 選択画像の AI 解析結果削除
- 選択フォルダのインデックス削除
- 顔認識データの全削除
- OCR データの全削除
- サムネイルキャッシュ削除
- DB 完全リセット

削除は元画像ファイルには一切影響しない（解析データのみを対象とする）。

## 4. 削除処理の安全設計

- 重複/類似/顔の整理操作で非保持画像を扱う際は、必ず確認ダイアログを表示する。
- 初期実装では「削除」ではなく隔離フォルダへの移動を既定とし、誤操作からの復旧を容易にする。
- 元画像ファイルの物理削除はユーザーの明示操作のみで行い、一括無確認削除は提供しない。

## 5. 共有前安全チェック（Phase 7 / 後続）

SNS 投稿・ファイル共有前に個人情報を検出する機能。MVP 非対象。

検出対象: 顔、ナンバープレート、住所、電話番号、メールアドレス、
クレジットカードらしき番号、身分証らしき画像、EXIF の GPS 位置情報。

共有用コピー作成機能（非破壊）:

- EXIF 削除 / GPS 情報削除
- 顔ぼかし / ナンバープレートぼかし
- OCR で検出した個人情報の警告

これらは元画像を変更せず、別ファイルとして共有用コピーを出力する
（`docs/architecture.md` および非破壊編集方針に準拠）。

## 6. 非破壊編集との関係

アップスケール・ノイズ除去・ぼかし等の編集は元画像を変更しない。
編集結果は別ファイルとして保存し、編集レシピを DB に記録、派生画像ツリーで
元画像との関係を管理する（引継ぎ文書 13章）。
